Codex로 옮길 때의 기준

  • Hook 설명은 Codex hooks 지원 여부를 먼저 확인한 뒤, hook으로 둘 것과 검증 명령으로 충분한 것을 나눕니다.
  • MCP 설명은 plugin, connector, app tool까지 포함해서 다시 분류합니다.
  • Agent orchestration은 subagents, browser workflow, parallel work 관점으로 다시 씁니다.
