Codex Skills와 재사용 루틴

Skill은 반복 작업을 저장하는 장치입니다. 모든 지식을 skill로 만들기보다, 자주 쓰고 검증 기준이 있는 일만 skill로 둡니다.

Skill로 만들기 좋은 작업

  • 매번 같은 입력과 출력 구조가 있는 작업
  • 검증 명령이나 리뷰 기준이 반복되는 작업
  • 공식 문서 확인, 요약, 발행처럼 절차가 중요한 작업
  • 브라우저 캡처, 문서 렌더링, 스프레드시트 처리처럼 도구 순서가 중요한 작업

Skill 대신 체크리스트가 나은 경우

  • 한 번만 하는 제품 판단
  • 프로젝트 맥락이 너무 강한 임시 결정
  • 아직 두 번 이상 반복해 보지 않은 흐름

Skill, agent, hook의 구분

  • Skill은 반복 workflow를 같은 대화 컨텍스트 안에서 재사용할 때 씁니다.
  • Subagent는 조사량이 많거나 역할과 권한을 분리해야 할 때 씁니다.
  • Hook은 도구 실행 전후에 검증, 차단, 알림 같은 정책을 자동화할 때 씁니다.

Agent 설계와 운영 기준에서 세 기준을 함께 비교합니다.

발행 기준

공개 문서에는 사용 시점과 검증 기준을 함께 적습니다.

기능 소개만 남기면 금방 낡습니다. 언제 쓰고, 언제 쓰지 않고, 무엇으로 확인하는지를 남겨야 오래갑니다.
