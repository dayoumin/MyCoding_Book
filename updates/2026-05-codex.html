관찰할 변화

Context Appshots

앱 화면 상태를 Codex가 이해하는 데 쓰이는 context 수집 기능입니다. UI 작업 설명 방식이 달라질 수 있습니다.

Planning Goal mode

장기 작업을 맡길 때 목표, 범위, 검증 기준을 더 잘 나눠야 합니다.

Browser In-app browser annotations

브라우저 화면에서 무엇을 봤고 무엇을 검증했는지 기록하는 방식이 중요해집니다.

Remote Mobile remote access

모바일에서 Codex 작업을 확인하거나 이어가는 흐름을 학습 대상으로 둡니다.

내 작업에 미치는 영향

  • 작업 요청은 "해줘"보다 목표, 범위, 검증 기준을 함께 줘야 한다.
  • 프론트엔드 작업은 코드 diff뿐 아니라 실제 화면 확인을 기본으로 둔다.
  • 긴 작업은 중간 산출물과 되돌릴 수 있는 단위로 나눠야 한다.
  • 새 기능은 곧바로 사이트에 쓰지 않고 playbook에 먼저 실험 기록을 남긴다.
