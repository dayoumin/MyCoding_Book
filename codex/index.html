Codex를 단순 코드 생성기가 아니라 작업 파트너로 쓰기 위한 학습 지도입니다. 이 섹션은 실전 작업 흐름, skill 재사용, 도구 연결, 브라우저 검증을 중심으로 확장합니다.

Codex 기준으로 바꾸는 이유

이전 MyCoding Book은 Claude Code의 skill, hook, MCP, orchestration을 중심으로 만들어졌습니다. 앞으로는 Codex 앱, CLI, browser workflow, subagents, hooks, connectors, skills를 중심으로 재정리합니다. Claude Code 자료는 삭제하지 않고 legacy로 보관합니다.
