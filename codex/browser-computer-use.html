Browser와 Computer Use

AI 코딩은 코드만 맞아서는 부족합니다. 화면에서 실제로 보이는지, 클릭되는지, 사용자가 이해할 수 있는지를 확인해야 합니다.

브라우저 검증이 필요한 경우

  • 프론트엔드 화면, 반응형 레이아웃, 접근성 변화
  • 로그인, 검색, 폼 제출처럼 실제 상호작용이 있는 기능
  • 로컬 앱과 외부 페이지가 함께 동작하는 흐름
  • 문서 사이트처럼 사람이 읽는 품질이 중요한 산출물

기록할 것

  • 확인한 URL
  • 주요 화면 제목과 콘솔 에러 여부
  • 클릭 또는 검색 같은 핵심 상호작용 결과
  • 남은 위험이나 확인하지 못한 범위
