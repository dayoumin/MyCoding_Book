Agentic Coding Roadmap

이 사이트는 단순한 Codex 사용법 모음이 아니라, agentic coding 시대에 맞춰 개발 환경이 어떻게 바뀌는지 계속 정리하는 개인 학습 시스템입니다.

큰 방향

1 Codex 운영 기준 확립

AGENTS.md, goal mode, browser verification, skills를 실제 작업 루프로 정리합니다.

2 Agentic stack 이해

벡터 저장소, RAG, multi-agent, eval, observability를 개발 기본 소양으로 편입합니다.

3 프로젝트 적용 패턴 만들기

새 프로젝트를 시작할 때 어떤 도구와 문서를 기본으로 둘지 템플릿화합니다.

4 월간 업데이트

공식 문서와 릴리스 노트를 확인하고, 낡은 설명을 legacy로 넘깁니다.

콘텐츠 확장 순서

Phase주제완료 기준
Phase 1Codex 기본 작업 루프작업 요청, 검증, 보고 방식이 문서화됨
Phase 2Agentic stackvector store, RAG, multi-agent, eval의 역할 구분
Phase 3실전 레시피PR 리뷰, UI 구현, 문서 업데이트, 운영 자동화 예시
Phase 4개인 템플릿새 프로젝트에 복사할 AGENTS.md와 학습 체크리스트

계획 문서가 필요한 이유

AI 코딩 환경은 기능 단위로 따라가면 금방 흩어집니다. 그래서 기능 목록보다 "내 작업 방식이 어떻게 달라지는가"를 기준으로 사이트를 확장합니다. 벡터 저장소와 멀티 agent도 새로운 유행어가 아니라, 앞으로 프로젝트 구조와 검증 방식에 직접 영향을 주는 기반입니다.
