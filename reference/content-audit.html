기존 자료 감사표

오래된 Claude Code 자료와 새 Codex 자료가 섞이지 않도록, 공개 문서와 원본 문서를 keep, rewrite, legacy, later로 나눈 작업 지도입니다.

분류 기준

상태 의미 다음 행동
Keep 현재 Codex 학습 흐름에 그대로 둬도 되는 문서 월간 업데이트 때만 확인
Rewrite 좋은 내용이 있지만 Codex 기준으로 다시 써야 하는 문서 공식 문서 확인 후 새 HTML로 승격
Legacy Claude Code 기준 설명으로 보관 가치가 있는 문서 현재 기준과 혼동되지 않게 legacy에서만 연결
Later 학습 주제로는 유효하지만 지금 핵심 흐름은 아닌 문서 roadmap 또는 backlog로 이동

우선순위 결론

  1. Codex hooks 문서는 작성 완료. 기존 Claude hook 자료를 Codex release behavior 기준으로 재분류했다.
  2. Custom agent 템플릿 문서를 작성했다. agent 설계 문서와 바로 이어지는 반복 역할 기준이다.
  3. MCP 문서는 Codex MCP, plugins, connectors, app tools까지 포함해 재작성했다.
  4. RAG와 vector store는 agentic stack의 하위 문서로 분리했고, agentic RAG 운영 기준을 추가했다.
  5. creative/practice 문서는 삭제하지 않고 예제 학습 자료로 유지하되, 나중에 최신화한다.
